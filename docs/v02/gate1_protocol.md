# v02 / Gate1：固定后续数据下的错误奖励持续性

日期：2026-10-12制定，2026-10-13更新，Asia/Shanghai。状态：**正式冻结已验收，五组T32正在执行，尚无终态科研结果**。用户已授权按科研开发规范开始工作。v01 的实验、源码、模型和六份现存完整状态保留。依据 [六个 Gate 协议](../v01/gate_protocol.md) 和 [研究问题](../RSI-Agent/idea.md#10-当前阶段的验证性实验)。本方案中的具体阈值和实现选择是本轮研究决断，不写成用户确认或此前已预注册。

## 假设与竞争解释

假设：在第8步只把一条具有显式错误答案的轨迹的终局 outcome 从0改为1后，即使第9–32步图像、token、observation、角色 mask、组成员、顺序及 reward 完全相同，两分支在第32步仍有超出数值波动和最小实际偏移的固定探针评分差异。竞争解释包括状态恢复不完整、重放输入不同、分母协议不同、探针受分支输出影响、随机波动以及只有短暂差异。

否证预测：末态配对差异区间完全落入预定容差内。区间跨越阈值、有效独立种子不足或关键审计缺失时为“不确定”。第8步有差异不构成长期持续性证据；本实验的“持续”仅指32步 horizon。

## 条件与样本

- 固定 v01 的 Qwen2.5-VL-3B、data08、混合奖励 alpha_out=1、原生 AdamW/GRPO、32步 cosine scheduler、每步4题×4轨迹、FSDP4/TP2。最多四张4090，物理4–7，分支串行。
- 五个独立 seed blocks：20261011、20261012、20261013、20261014、20261015。前三个是预定复用的历史训练种子；后两个补充独立源路径。复用全部三组，不能根据其后续损害选择。已见 v01 正常准确率属于既有证据，不能声称所有数据此前未看过。
- k=8，T=32；每组共用完整 S7 和同一 U8。目标按稳定 trajectory ID 排序选择第一条显式错误且未截断、客观 outcome=0 的轨迹，仅修改终局分量。全组 advantage 使用原生函数重算。
- 无合格目标记录 `no_eligible_target`，保留该组全部记录，不向后寻找新 k，不补种子、不提高错误强度。统计报告全部五组及有效组；有效组少于3时主结论必须“不确定”。区间以有效训练种子为单位，条件性结论不推广到无合格目标的运行。
- 每组生成或核验一条无注入的 source history；源路径后续结果不用于选目标或调阈值。Clean-fixed、Corrupt-fixed 和 Clean-repeat 均重放同一 U9:32，当前 actor 分母与 optimizer 沿各自路径演化。这是 native reanchor 机制干预，不声称 on-policy 或 importance-corrected。

## 指标与判定

主指标是固定 probe split 的 `D_score[T]`。Solver 使用每题预定的 `\boxed{正确答案}` 和 `\boxed{正确答案+1}`；Verifier 使用预列的接受、拒绝 JSON。两类候选在运行前固定，不取受污染分支的输出、不筛选有差异的 token。正确答案只由评测器用于构造固定探针，不进入训练或目标选择。这些候选衡量声明探针上的评分漂移，不能代表完整生成分布的 KL 或所有能力。

实施前审查修订：最初提案的 `Final answer: 0/1` 不符合实际 Solver 的 boxed 输出格式，且与题目答案量级缺乏对应。2026-10-12在任何正式 corrupt 后续实验之前改为上述正确/加一候选；原短候选 inputs 和运行中的工程 control 留作原始验证记录，不用作正式评分或正式数值阈值校准。新候选的变长 padding、attention/角色 mask 与实际评分过滤需重新验收。

每条记录保存相同图像/前缀/候选 token/角色 mask 的 hash 和逐 token 原生 actor teacher-forced log-score。先在每个 case/role 内对各候选及 Verifier 正误上下文等权平均 token 平方差，再开方；按 case 平均，再对 Solver/Verifier 两角色等权平均。题目、候选和 token 都不是独立训练重复。

Clean-repeat 是同完整起点、同固定数据的额外 clean 分支，逐组给出数值 floor；不把五个数值 floor 解释为准确的95%分位数。主配对量 `Q_s = D(Clean,Corrupt)_s - D(Clean,Clean-repeat)_s - epsilon_D`，不把负数截断。报告五组数值、均值及双侧95% Student-t 区间，并明确小样本分布假设。区间下界>0为“支持”；上界≤0为声明容差内的“否证”；否则“不确定”。

`epsilon_D` 的最小实际偏移提案为0.01 nat/token。单 token 的 log-prob 若变化0.01，其对应条件概率比为 exp(0.01)≈1.01005；这里只提供量级参考，RMS聚合不保证每个 token 都有相同变化，也不等于完整策略的 odds 变化。该值仅是声明探针的研究容差。实际阈值还须参考独立 clean 数值校准，**在任何正式 corrupt 后续结果生成前冻结**；不可根据末态差异调整。初始、8、16、24、32步曲线与 held-out 256题显式答案正确率为辅助，不因辅助指标阳性而改换主终点。

## 资源与停止规则

正式启动前冻结累计实际存储预算，覆盖源路径、prefix、三个固定分支、完整状态共存峰值、raw 和安全余量。新运行仅在新完整状态提交后滚动退役自身非保护旧点。现有 v01 六状态不删除。只有逐字段证实 Clean-fixed 完整末态与 source 完全相等后，才能对 v02 重复权重去重；保留完整可恢复 source、证书和去重证明。若不相等，保留现场并重新预算，不以假定等价释放空间。

长期保留五组共同 S7、全部 source history/source S32 和 Corrupt-fixed S32。Clean-fixed、Clean-repeat 及工程 control 的完整状态是临时验收资产。正式启动前的资源修订（2026-10-13）：保持 clean→corrupt→repeat 顺序；clean 的25个原生单位、全部评分/评测和完整S32先独立验收，再实际认证保留source S32并逐字段验证两者等价，保存不可变 `clean_source_dedup` 证明后，才退役 clean 自己的 model/optim 大分片。此时 paired 组仍待验收，空 pending 仅指 clean 物理权重依赖；corrupt/repeat 从共同完整S7恢复，使用已保留的固定history、raw/scores与完整指纹。最终 paired 证明重建并核对原early证明和clean退役收据，组验收后仅退役repeat，不能更换clean的原proof SHA。工程control须按其独立完整验收证明退役。全部状态证书、完整指纹、RNG/cursor、小元数据和明确退役收据保留。需要复查这些模型时，从保留的 S7、全部固定历史、代码快照和种子重建；不能声称退役点仍可直接恢复。运行中或失败未验收的状态不按此规则退役。预算按此事前保留策略计算，不依赖未来 clean/source 是否碰巧相等。

P0/P1 实现问题、恢复/固定 unit 审计失败、NaN/Inf、资源不足时停止依赖阶段，保留日志和最后有效状态。阴性、失败和中断如实报告；不按效果方向提前停止或增加预算。
