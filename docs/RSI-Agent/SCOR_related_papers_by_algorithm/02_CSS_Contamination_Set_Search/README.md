| 01 | [A Snapshot of Influence: A Local Data Attribution Framework for Online Reinforcement Learning](https://papers.nips.cc/paper_files/paper/2025/file/377d0752059d3d4686aa021b664a25dd-Paper-Conference.pdf)<br>NeurIPS 2025 | Online RL 中训练 experience 会改变当前 policy，并进一步改变未来采集的数据，固定数据集假设下的数据归因方法难以直接使用。 | 在训练 checkpoint 上进行 local data attribution，用训练记录梯度与目标行为或累计回报目标的梯度相似度估计 influence，并用 Iterative Influence-based Filtering 过滤有害经验。 | 针对指定 checkpoint 和 target function 计算每条训练记录的局部影响；分别考虑 action 与 cumulative return 目标；高影响记录可被过滤，再观察 policy 的行为变化。 | 局部梯度相似度可概括为 $I(z_i;T)=\langle\nabla_\theta\ell(z_i;\theta),\nabla_\theta T(\theta)\rangle$。它衡量训练记录 $z_i$ 的更新方向与目标 $T$ 的变化方向是否一致。 | CSS 最直接的算法底座。SCOR 需要在此基础上加入 delayed historical reward revision，并追踪 $\delta\theta_k\rightarrow\delta D_{k+1}\rightarrow\cdots$ 的 descendant contamination。 | CSS 无需从零发明 influence estimator；主要创新可以放在跨 outer-loop 传播、随机分叉校准、污染集恢复与主动 probe。 |
| 02 | [Understanding Black-box Predictions via Influence Functions](https://proceedings.mlr.press/v70/koh17a/koh17a.pdf)<br>ICML 2017 | 逐个删除训练样本再完整重训才能知道其影响，计算成本过高。 | 利用 influence function 近似“对某个训练样本施加微小 upweight”后参数和测试损失如何变化。 | 先求训练目标 Hessian 与单个样本梯度，再用 inverse-Hessian-vector product 估计该样本对参数和指定测试点的影响，无需逐样本重新训练。 | $I_{up,loss}(z,z_{test})=-\nabla_\theta L(z_{test},\hat\theta)^T H_{\hat\theta}^{-1}\nabla_\theta L(z,\hat\theta)$。负值与正值分别表示 upweight 后对目标损失的不同影响方向。 | CSS 的经典 baseline，可在小模型或受控环境中估计第 $k$ 轮训练事件对后续状态的局部影响。 | 大型 VLM 上 inverse Hessian 成本高，适合作为理论参照或小规模 benchmark，而非 SCOR 主实现。 |
| 03 | [Estimating Training Data Influence by Tracing Gradient Descent](https://proceedings.neurips.cc/paper/2020/file/e6385d39ec9394f2f3a354d9d2b88eec-Paper.pdf)<br>NeurIPS 2020 | Influence Functions 需要 Hessian 近似，在深度网络中计算昂贵且局部二阶假设容易失效。 | 沿真实训练轨迹保存多个 checkpoint，用训练样本与目标样本梯度的点积累计影响。 | 训练时周期保存参数 checkpoint；在每个 checkpoint 上计算 source 和 target 的梯度相似度；使用学习率加权后跨 checkpoint 求和，得到训练过程中的累计 influence。 | $TracInCP(x,x_j)=\sum_i\eta_i\,g_{\theta_i}(x)^Tg_{\theta_i}(x_j)$，其中 $\theta_i$ 为 checkpoint，$\eta_i$ 为对应学习率。 | SCOR 本来就需要 outer-loop checkpoint，TracIn 很适合成为 CSS 的低成本历史 influence baseline。 | CSS 可以先用 TracIn/gradient alignment 粗筛候选污染轮次，再对边界样本执行更昂贵的 counterfactual probe。 |
| 04 | [Causal Agent Replay: Counterfactual Attribution for LLM-Agent Failures](https://arxiv.org/pdf/2606.08275.pdf)<br>arXiv 2026 | LLM Agent 的失败轨迹具有随机性，仅靠日志相似度或 LLM judge 很难确定哪个决策真正导致最终失败。 | 把 Agent execution 建模为结构因果过程，对特定步骤实施 intervention，再从该点向后多次 replay，利用结果分布变化估计因果贡献。 | 选择候选步骤，替换该处 action 或决策；保持其余可控条件一致，多次重新运行 stochastic policy；比较 factual 与 intervention outcome distribution，并用置信区间和 Monte-Carlo Shapley 处理多步交互。 | 单步因果效应可概括为 $\Delta_t=\mathbb E[Y\mid do(A_t=a_t')] - \mathbb E[Y]$；多次 replay 用于估计该期望及其置信区间。 | CSS 的 Active Contamination Probe 和 TRA 的随机性校准都可借鉴 CAR。 | 单次 replay 的差异不适合作为污染或 trajectory 失效证据；重复 replay 与置信区间可以成为 SCOR 稳定判定的统计基础。 |
| 05 | [Machine Unlearning](https://arxiv.org/pdf/1912.03817.pdf)<br>IEEE S&P 2021 | 删除训练数据后从头 retrain 才能得到干净模型，成本与原训练基本相同。 | 提出 SISA：Sharded、Isolated、Sliced、Aggregated。预先切分训练数据并保存 slice checkpoint，删除数据时只重训受影响 shard 的必要后缀。 | 数据先分成互相隔离的 shards，每个 shard 再按时间切成 slices；每个 slice 后保存 checkpoint；删除请求定位到对应 shard/slice，从前一 checkpoint 重训该 shard，最后重新 aggregate constituent models。 | 可抽象为 $D=\bigsqcup_{s=1}^SD_s$，$D_s=D_{s,1}\oplus\cdots\oplus D_{s,R}$，最终 $f(x)=Agg(f_1(x),\ldots,f_S(x))$。 | SCOR 整体 selective rollback 的直接祖先。SISA 的受影响范围由预先分片确定，SCOR 的 $C_k$ 需要从 self-generated training path 中动态搜索。 | SCOR 可以继承 checkpoint/slice 的工程思想，把新贡献集中在“动态污染范围如何发现”。 |
| 06 | [DeltaGrad: Rapid retraining of machine learning models](https://proceedings.mlr.press/v119/wu20b/wu20b.pdf)<br>ICML 2020 | 训练数据发生少量增删后，全量重训浪费大量与原训练重复的梯度计算。 | 缓存原训练过程中的参数和梯度，利用 Taylor 展开与 L-BFGS 近似数据变更后的新梯度，只周期性执行精确更新。 | 原训练阶段保存 $w_t$ 与 gradient；数据变更后，用参数差与 Hessian 近似估计新模型的梯度变化；以 L-BFGS 构造低成本 quasi-Hessian，并定期执行 exact gradient refresh 控制累计误差。 | $\nabla F(w_t^I)\approx\nabla F(w_t)+H_t(w_t^I-w_t)$，实际使用 L-BFGS 近似 $H_t$。 | 可用于降低 SCOR Reuse/Correct 的重训练成本，尤其适合历史 computation 已保存的情况。 | SCOR 的论文贡献无需放在“怎样更快重算梯度”上，可以复用 DeltaGrad 类方法作为工程加速或 baseline。 |
